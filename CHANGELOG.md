# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-05-14

- Added bidirectional conversion between CPA (`codex`) and Sub2API JSON formats
- Added browser UI for paste-based conversion
- Added `.json` upload and conversion download flow
- Added `.zip` batch conversion with `converted_<timestamp>.zip` output
- Added configurable JSON download naming options in the UI
- Added favicon and updated branding
